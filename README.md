# Temp-logger
Making a temperature logger and seeing if I can add my own twist to it 

Main goal is to build a system that:
  - reliably measures the temperature
  - give time stamps for the live readings
  - clean csv over Serial
  - learning sensor faults
  - practising c++ and becoming more fluent

Hardware

  - ESP 32 Wrover-e
  - Researched between the DHT22 and the DS18B20, going with the DS18B20 due to its more durable nature and being more accurate ( waterproof)
  - Breadboard
  - Jumper wires
  - LED's
